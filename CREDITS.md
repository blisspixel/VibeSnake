# Credits

Status: release-material foundation. Final candidate content and platform credits are pending.

## Vibe Snake

Vibe Snake is developed in the public [VibeSnake repository](https://github.com/blisspixel/VibeSnake). Source code, project-authored documentation, and content explicitly cleared by the content policy are licensed under the [Apache License 2.0](LICENSE).

The native product uses Godot 4.7.1 .NET with pure C# rules and persistence. The Python and Pygame implementation remains a frozen behavior reference and temporary alpha, not the 1.0 player runtime.

## Art and identity

- Project logo: preferred handcrafted 1024 by 1024 Vibe Snake mark retained from the Snakev2 asset lineage.
- Radio station badges: deterministic rasterization from project-owned 5 by 7 pixel glyphs.
- Native fallback cues: finite procedural cues generated locally from project-owned code and declared in packaged qualification evidence.

## Music and radio

The public source tree contains an eight-station, 95-track radio library. No track is approved for a player release merely because it is present in source. Candidate selection, complete media review, exact provenance, listening review, credits generation, and export-eligible pack manifests remain release gates. The final credits must list only content in the exact approved candidate manifests.

## Third-party software

Godot, .NET, the temporary Python runtime, Pygame CE, and development dependencies retain their own licenses and notices. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Final player artifacts must include notices derived from the exact lock-bound dependency inventory and packaged runtime, not from the broader development environment.
