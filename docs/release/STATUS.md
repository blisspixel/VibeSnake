# Current Status

Snapshot date: 2026-08-22

## Executive assessment

Vibe Snake is a substantial alpha with a reliable engineering baseline on GitHub. The canonical repository is [blisspixel/VibeSnake](https://github.com/blisspixel/VibeSnake): a single `main` branch, pull requests and other public intake disabled, hosted CI running on every push, and failures fixed forward before unrelated work continues. The active ruleset requires `CI complete` subject to the documented repository-admin bypass; a bypassed revision cannot publish `player-latest` until the complete workflow succeeds.

**Product path:** Godot 4.7.1 .NET + pure C# rules/persistence. Hosted runners export and smoke native players outside the checkout on Windows, macOS, and Linux **without Python**. All nine powers are complete pure C# contracts; the Godot shell renders markers, HUD, multi-power feedback, Slow-Mo/Boost cadence, achievements unlocks/browse, and logical input.

**Python/Pygame:** Frozen behavior oracle and optional migration player. Not the default launcher or the 1.0 runtime. Dual-runtime JSON fixtures exist only so C# can prove parity with the oracle. New player features belong in `native/` and `game/`, not in expanding Python gameplay.

The public checkout still includes the eight-station offline radio library (95 tracks), the frozen Python presentation, and its reference CLI (`vibesnake play|update|status|doctor|version`). Root `play.ps1`, `play.sh`, and `play.bat` now verify, build, and launch the native Godot game. Continuous [player-latest](https://github.com/blisspixel/VibeSnake/releases/tag/player-latest) publishes a source ZIP, Python reference wheel and sdist, and checksums only after the exact same-repository `main` push passes CI; it is not a signed packaged player or supported Agent Plugin. Pack export approval (`exportEligible` still zero), protected platform signing, selected-store integration, physical-controller evidence, HW frame evidence, and structured playtesting remain open.

Exact [Release run 32421705560](https://github.com/blisspixel/VibeSnake/actions/runs/32421705560) passes at clean `main` revision `e87db6e` and retains the unsigned Windows x64, macOS Universal, and Linux x64 review packages, cross-bound matrix, manifests, qualification evidence, and detached provenance. The matrix records 300 clean launches, 600,000 reliability comparisons, 300 spectator restarts, 21 injected faults, 360 performance samples, and 24 maximum-text-scale display rows. Publication eligibility remains false pending physical review, approved content, signing, and channel decisions.

The ignored physical-review workspace has now been generated from an independent recomputation of that matrix. Its candidate record binds the exact revision, version, run, three package hashes, three manifest hashes, file names, sizes, and four platform rows. The manual validator refuses unbound or mismatched sessions; current execution remains 0 of 144 cells.
