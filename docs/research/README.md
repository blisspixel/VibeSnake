# Research and Working Inputs

This directory records research policy and durable source links. It does not store copied provider documentation, raw generated research, production prompts, or lyric drafts. Those materials are not canonical product evidence and may carry different redistribution terms.

Current product decisions belong in [game design](../design/GAME_DESIGN.md), [fun design](../design/FUN_DESIGN.md), [audio](../content/AUDIO.md), [status](../release/STATUS.md), or the [roadmap](../../ROADMAP.md). Canonical documents cite primary sources next to durable claims. Provider behavior and terms must be checked against current official sources before a decision depends on them.

Useful primary entry points include the [Python version status](https://devguide.python.org/versions/), [Godot documentation](https://docs.godotengine.org/), [GitHub large-file guidance](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github), [ElevenLabs terms](https://elevenlabs.io/terms-of-use), and [ElevenLabs commercial-use guidance](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform).

Do not place credentials, secrets, private player data, or verbatim third-party documentation in this directory.
